# RotorStudio

RotorStudio is being migrated in Stage 1 to a Fortran 2018 numerical core plus a GUI-independent Python scientific core.

The current implementation increment is Stage 1 M2. MATLAB V2 remains the numerical/behavioral authority. MATLAB/Octave equivalence gates remain BLOCKED until an authoritative runtime baseline is executed.

See the Stage-1 implementation branch / pull request for the Fortran, Python, tests, examples and qualification evidence.
