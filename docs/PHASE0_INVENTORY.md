## Scope rule

A_SOLVER cases execute the preserved V2 solver through pinned Octave 7.1.0 and trace calls that are compared with the Fortran/Python implementation. B_ANALYTICAL cases remain independent educational/analytical regressions and are not reimplemented inside the production solver.
