# Known Rotor_Software_v2 legacy issues

These are authority behaviors/defects; they are not silently corrected.

| Item | V2 behavior | Stage 1 treatment |
|---|---|---|
| `shftasym.m` default AxialForce | function has 9 inputs but checks `nargin < 8`; an 8-argument call leaves `AxialForce` undefined | runtime probe + explicit compatibility guard |
| `shftasym.m` axial branch | nonzero axial load writes to undefined `Kre` | runtime defect probe; production compatibility path rejects unsupported nonzero asymmetric axial load |
| `shftasym.m` rotary `Cs` | `Ms` is scaled and reused in `Cs = rhoI*Ms/(15*L)`, introducing nonlinear rhoI scaling | preserved where applicable; runtime characterized |
| `bearasym.m` type 4 | writes reverse rotational term to `K1b1(2,1)`; never writes `K1b1(4,3)` | preserved and tested |
| `chr_asym.m` | one-output path includes `K1b`; two-output path omits it | API preserves output-dependent semantics |
| `time_fdn.m` / `freq_fdn.m` | predicate `type > 2 | type < 9` is tautological for finite numeric bearing types | documented and preserved |
| `runup.m` | defines `jot` but also uses built-in `j` | runtime characterized; V2 forcing semantics preserved |
| Manual transient reduction | manual describes Guyan/static reduction, V2 uses modal truncation | `DOCUMENTATION_MISMATCH`; V2 preserved |

Pinned Octave runtime evidence is generated by `validation/legacy_cases/run_octave_probes.m`.
